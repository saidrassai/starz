# ⭐ jorgesandoval/llm-post-training-from-scratch

CPT · SFT · DPO · GRPO implemented from scratch in PyTorch. An educational, hands-on walkthrough of the four core LLM post-training techniques — continued pre-training, supervised fine-tuning, direct preference optimization, and group relative policy optimization — with manual LoRA, no TRL/PEFT. One Jupyter notebook per stage.
